VELTRIX — LOCAL WORKSPACE 1.1

STARTEN
1. ZIP-Datei entpacken.
2. Den Ordner „VELTRIX-Local-Workspace“ öffnen.
3. „index.html“ doppelklicken.
4. Die Anwendung läuft lokal im Browser. Kein Konto, kein Hosting und kein Server erforderlich.

FUNKTIONEN
- Dateien oder Ordner als Einträge hinzufügen
- Einträge durchsuchen und nach Kategorien filtern
- Favoriten markieren
- Kategorien erstellen
- Notizen zu Einträgen speichern
- Workspace-Einträge entfernen, ohne Originaldateien zu löschen
- Daten bleiben im lokalen Browser-Speicher

WICHTIG
Aus Sicherheitsgründen dürfen normale Webseiten nicht frei die gesamte Festplatte durchsuchen oder Dateien ohne Auswahl öffnen. Deshalb wählst du Dateien/Ordner selbst aus. VELTRIX speichert die Einträge und Metadaten, nicht die Datei-Inhalte. Es verschiebt, löscht oder lädt deine Originaldateien nicht hoch.

Die Einträge werden im lokalen Speicher dieses Browsers gehalten. Wenn du Browserdaten löschst oder einen anderen Browser verwendest, können sie verschwinden. Diese Version ist eine lokale Browser-Anwendung, keine eigenständige Windows-EXE.
